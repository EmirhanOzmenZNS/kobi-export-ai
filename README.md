# KOBİ Visual Admin Editor

Özellikler:
- Admin giriş: kullanıcı adı admin, şifre 0000
- Ön yüz benzeri görsel editör
- Öğeye tıklayıp yazı, renk, boyut, konum değiştirme
- Başlık, açıklama, marka adı, renkler, kart köşeleri, buton yüksekliği, panel konumu, panel genişliği, görünürlük
- Ayarlar tarayıcı localStorage içinde saklanır

Çalıştırma:
Backend:
cd backend
pip3 install -r requirements.txt
python3 app.py

Frontend:
cd frontend
npm install
npm run dev
